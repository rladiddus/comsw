# test/ — Supabase 전환 검증용 사본

이 폴더의 `*_supabase_test.html` 파일들은 Apps Script → Supabase 전환 과정에서
사용한 **검증용 사본**입니다. 운영 페이지는 저장소 루트의 동일 이름(접미사 없는)
파일이며, 메인 메뉴/네비게이션은 모두 루트 운영 파일을 가리킵니다.

- 운영본과 기능은 동일하지만 보관 목적이라 루트에서 분리해 두었습니다.
- 에셋 경로는 한 단계 위(`../assets/...`, `../index.html`)를 참조하도록 보정되어
  데이터 로드는 정상 동작합니다.
- 단, 공통 하단 메뉴(`footer-menu.js`)의 페이지 이동은 루트 기준 상대경로(`./`)를
  쓰므로, 이 폴더에서 다른 메뉴로 이동하는 동작은 보장되지 않습니다(보관용).

운영 파일을 수정할 때 이 사본까지 함께 고칠 필요는 없습니다. 더 이상 필요 없어지면
이 폴더를 통째로 삭제해도 운영에는 영향이 없습니다.
