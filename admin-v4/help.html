컴수원 관리 사용방법

"~할 때" 찾아보세요. 제목을 누르면 어디서 무엇을 하는지 펼쳐집니다.

학과장·관리자 강사

먼저 알아 두기

  • 무엇을 바꾸면 오른쪽 아래에 창이 뜹니다. 취소 = 방금 바꾼 것 되돌리기, 임시 저장 = 홈페이지에 내지 않고 보관, 사이트 적용 = 홈페이지에 반영.
  • 임시 저장한 뒤에는 되돌리기가 나옵니다. 누르면 임시 저장한 것까지 버리고 지금 홈페이지 상태로 돌아갑니다.
  • 오른쪽 아래 창이 버튼을 가리면, 창의 빈 곳(제목 등)을 마우스로 끌어 옮기세요. 위치는 기억되고, 제목을 두 번 누르면 원래 자리로 갑니다.
  • 사이트에 적용하는 동안은 화면이 어둡게 막히고 "사이트에 적용 중입니다"가 돕니다. 끝날 때까지 기다리세요.
  • 학과 추가·이름 수정, 과목 만들기·삭제·복원은 누르면 바로 반영됩니다.
  • 화면이 예전 모양으로 보이면 키보드 Ctrl + Shift + R로 새로고침하세요.

강사

강사가 커리큘럼을 제출했을 때(검수·확정)
  1. 강사 메뉴에서 "이번 제출" 칸에 커리큘럼 N건이 있는 강사를 누릅니다.
  2. 팝업의 커리큘럼 탭 → 왼쪽에서 "이번 제출" 표시가 있는 과목을 고릅니다.
  3. 단계마다 원래 문구(강사가 쓴 글)와 홈페이지 문구를 고칩니다(홈페이지 문구를 비우면 원래 문구가 그대로 나갑니다).
  4. 4단계보다 적으면 + 단계 추가로 채우고 원래 문구를 씁니다. 4단계보다 많으면 지울 단계 카드 오른쪽 위 ×.
  5. 문장을 다듬고 싶으면 다듬을 단계의 AI 다듬기만 체크하고 AI 문장 다듬기.
  6. 이미지가 없거나 바꾸고 싶으면 이미지(또는 "이미지 없음")를 누르거나 이미지 수정.
  7. 그대로 승인하면 확정, 고쳤다면 오른쪽 아래 사이트 적용(같은 확정입니다).

정확히 4단계일 때 확정됩니다. 학과장·관리자가 직접 채우거나 지울 수 있어서 강사에게 다시 받지 않아도 됩니다. 번호는 화면 순서대로 1단계부터 다시 매겨집니다.

이미 확정된 강사 커리큘럼을 고쳐야 할 때
  1. 강사 → 강사 누르기 → 커리큘럼 탭 → 과목 고르기.
  2. 팝업 위쪽 닫기 옆 수정을 누릅니다.
  3. 원래 문구(강사가 쓴 글)·홈페이지 문구·이미지를 고칩니다. AI 문장 다듬기(수정 끝 왼쪽)는 고친 원래 문구를 바탕으로 다듬습니다.
  4. 4단계를 넘는 커리큘럼(예: 8단계)은 지울 단계 카드 오른쪽 위 ×를 누릅니다. 4단계보다 적으면 + 단계 추가. 저장하면 남은 단계가 1단계부터 다시 번호가 매겨집니다.
  5. 오른쪽 아래 사이트 적용. 고치기 전 내용은 기록으로 남습니다.
강사가 프로필·사진을 제출했을 때(AI 프로필 사진)
  1. 강사에서 "이번 제출"에 프로필이 있는 강사를 누릅니다 → 프로필 탭.
  2. 경력·한마디를 확인하고 필요하면 고칩니다.
  3. 강사가 본인 사진을 올렸으면 AI 프로필 사진 만들기 → 만들어진 사진을 확인합니다.
  4. 확정하면 홈페이지에 반영됩니다(홈페이지 노출 여부는 그대로).
강사를 홈페이지에서 숨기거나 다시 보일 때
  1. 강사 목록의 홈페이지 노출 스위치를 끄거나 켭니다.
  2. 오른쪽 아래 사이트 적용.
새 강사를 직접 등록할 때(강사 계정 없이)
  1. 강사 위쪽 거르기 줄 오른쪽 + 강사 추가.
  2. 이름·성별·학과·담당 과목·경력·한마디·사진을 입력하고 홈페이지 노출을 정합니다.
  3. 담당 과목은 과목 검색 → 과목 이름·학과·방학 특강으로 걸러 줄을 눌러 고르고 확인. 고른 과목은 알약으로 보이고 ×로 뺍니다.
  4. 저장 → 바로 반영됩니다.
강사 정보(경력·한마디·사진·학과·담당 과목)를 직접 고칠 때

강사 → 강사 누르기 → 프로필 탭 → 위쪽 정보 수정 → 고치고 저장(바로 반영). 강사가 제출하지 않아도 됩니다.

학과·담당 과목은 체크한 그대로 바뀝니다. 체크를 풀면 그 연결이 없어지고(강사 소개에서 그 학과에 안 나옴), 강사가 수업 설정에서 고른 내용도 함께 바뀝니다.

강사를 빨리 찾고 싶을 때

강사 위쪽에서 이름(검색), 학과, 홈페이지 노출(On/Off)로 걸러 봅니다.

학과·과목

새 학과를 만들거나 학과 이름을 바꿀 때
  1. 학과·과목 › 학과 구성에서 + 학과 추가, 또는 학과를 고르고 학과명 수정.
  2. 이름을 쓰고 추가/수정 → 바로 반영됩니다(사이트 편집의 학과 대표 화면에도 생깁니다).
학과 순서를 바꾸거나 학과를 홈페이지에서 숨길 때
  • 순서: 학과 구성 위쪽 학과 알약을 끌어서 옮깁니다(붉은 점선 자리에 놓기).
  • 숨기기: 학과를 고르고 학과명 수정 옆 공개 스위치를 끕니다(알약이 점선·회색).
  • 오른쪽 아래 사이트 적용.

숨긴 학과도 관리 화면에서는 계속 보이고 고칠 수 있습니다. 다시 켜고 사이트 적용하면 홈페이지에 돌아옵니다.

새 과목을 만들 때(일반 수업)
  1. 학과·과목 › 과목 생성에서 이름을 쓰고 만들기.
  2. 학과 구성에서 학과를 고르고 아래 과목 넣기로 그 학과에 넣은 뒤 사이트 적용.

학과·과목에서 만든 과목은 일반 과목입니다. 방학 특강 과목은 방학 특강 메뉴에서 따로 만듭니다(이름이 같아도 다른 과목).

학과 안에서 과목 순서를 바꿀 때

학과 구성에서 줄 왼쪽 손잡이(⠿)를 잡고 끌어서 놓습니다(놓을 자리에 붉은 점선). → 사이트 적용.

학과 커리큘럼(기간·과정내용·프로그램·학습수준)을 고칠 때
  1. 학과 구성 표에서 바로 고칩니다. 기간은 숫자만, 학습수준은 ★ 개수를 고릅니다.
  2. 과정내용을 AI로 만들려면 그 과목 칸 오른쪽 아래 체크를 켜고 위쪽 AI 정리(공통 4단계를 01~04 네 줄로 정리).
  3. 사이트 적용.

이 정보는 과목에 붙어 있어서, 같은 과목을 쓰는 다른 학과에도 함께 바뀝니다.

과목의 공통 4단계 커리큘럼을 만들 때
  1. 과목 이름을 누르면 팝업이 열립니다(학과 구성·전체 과목 어디서든).
  2. 팝업 위쪽 수정 → 왼쪽에서 참고할 강사를 체크합니다(검수 완료된 강사만 나옵니다).
  3. AI로 만들 단계만 체크하고 AI 공통 정리 → 문구를 확인·수정합니다.
  4. 단계마다 후보 이미지 중 대표 이미지를 누릅니다(다시 누르면 빼기).
  5. 오른쪽 아래 사이트 적용.
과목 이름을 바꿀 때

과목 이름을 눌러 팝업 → 수정 → 왼쪽 과목명 수정 → 새 이름 → 수정(바로 반영).

과목을 지우거나 되살릴 때
  • 지우기: 전체 과목에서 과목을 누르고 팝업 왼쪽 과목 삭제. 자료는 보관됩니다.
  • 되살리기: 삭제된 과목에서 복원. 학과·방학 특강에는 다시 넣어야 합니다.
과목을 빨리 찾고 싶을 때

전체 과목 위쪽에서 과목(검색), 학과, 방학 특강(On/Off)로 걸러 봅니다.

준비물

과목 공통 준비물을 정리할 때
  1. 준비물 메뉴에서 과목 줄을 누릅니다(또는 과목 팝업의 공통 준비물).
  2. 강사 준비물 가져오기로 강사들이 적은 것을 모은 뒤 정리하고, 필요하면 + 항목.
  3. 사이트 적용.

"캐드"에 적으면 캐드1·캐드2 모두에 적용됩니다. 위쪽 거르기로 "공통 준비물: 없음"을 고르면 아직 정리 안 한 과목만 볼 수 있습니다.

로드맵

학과 로드맵을 만들거나 고칠 때
  1. 로드맵에서 학과를 고릅니다(기본 순서 = 학과 구성 순서).
  2. 두 과목을 한 단계로 묶으려면 과목 사이 +를 켭니다(초록이면 묶임).
  3. 순서를 바꾸려면 과목 상자를 끌어서 옮깁니다 → "학과·과목의 순서와 다릅니다" 표시. 원래대로는 학과·과목의 순서와 동기화.
  4. 아래 단계 카드에서 문구를 쓰거나 AI 요약.
  5. 사이트 적용.
같은 단계 문구를 다른 학과에도 똑같이 쓰고 싶을 때

단계 카드의 타학과 동기화를 체크하고 사이트 적용하면, 과목 묶음이 똑같은 다른 학과 단계도 이 문구로 바뀝니다(한 번 맞춤).

방학 특강

새 방학 특강을 열 때
  1. 방학 특강에서 + 새 방학 특강 → 이름 쓰고 추가(공개는 꺼진 채로 만들어집니다).
  2. 과목 생성에서 특강 과목을 만들 때 "OO방학특강에 넣기"를 고르면 바로 그 특강에 들어갑니다.
  3. 이미 있는 특강 과목은 특강 화면 왼쪽 아래 과목 넣기로 넣습니다.
  4. 준비되면 제목 오른쪽 공개 스위치를 켜고 사이트 적용.

강사는 특강에 들어간 과목만 "내 커리큘럼 › 방학 특강"에서 고를 수 있습니다.

방학 특강 과목의 공통 커리큘럼을 만들 때
  1. 방학 특강에서 특강을 고르고 왼쪽 과목을 누릅니다("적용 전" 과목은 먼저 사이트 적용).
  2. 오른쪽 수정 → 강사 체크 → AI 공통 정리 → 대표 이미지 → 사이트 적용.
방학 특강 이름을 바꿀 때

특강 설정 제목 옆 이름 수정 → 바로 반영됩니다.

특강·세미나 / 사이트 편집

특강·세미나를 올리거나 고칠 때

특강·세미나에서 포스터와 내용을 입력하고 오른쪽 아래 사이트 적용.

메인 화면·로딩 화면 이미지를 바꿀 때
  1. 사이트 편집 → 메인 화면 또는 로딩 화면.
  2. 카드의 수정 → 이미지를 누르거나 끌어다 놓고, 문구·사용 스위치를 정한 뒤 확인. 새로 넣으려면 + 항목.
  3. 카드를 누르면 오른쪽에 미리보기 → 사이트 적용.
학과 대표 화면(표지 이미지·소개·영문 이름)을 바꿀 때

사이트 편집 › 학과 대표 화면 → 학과 고르기 → 수정 팝업에서 고치고 확인 → 사이트 적용.

홈페이지 아래쪽 메뉴의 위치·순서·이름을 바꿀 때

사이트 편집 › 하단 메뉴에서 메뉴를 끌어 왼쪽·오른쪽과 순서를 바꾸고, 이름은 수정. 메뉴 안 스위치를 끄면 홈페이지에서 숨겨집니다(회색 글자). → 사이트 적용.

이럴 땐

"반영하지 않은 다른 변경이 있어 멈췄습니다"가 뜰 때

예전 관리 화면 등에서 고치고 아직 공개하지 않은 변경이 있다는 뜻입니다. 화면 위쪽 빨간 안내의 같이 반영을 누른 뒤 다시 하세요.

실수로 바꿨을 때
  • 방금 바꾼 것만: 오른쪽 아래 취소.
  • 임시 저장한 것까지 모두: 되돌리기.
이미지를 올릴 때
  • 이미지(또는 "이미지 없음")를 누르면 고르기 창이 뜹니다. 파일을 고르거나 끌어다 놓으세요. PNG·JPG·WEBP.
  • 커리큘럼 이미지는 올리기 전에 홈페이지 카드에 보일 부분을 고릅니다: 마우스 휠로 확대·축소, 끌어서 위치 이동 → 이 부분으로 첨부. 크게 보기에서는 원본 전체가 보입니다.

먼저 알아 두기

  • 쓰고 나면 오른쪽 아래에 창이 뜹니다. 임시 저장 = 나만 보관(나중에 이어 쓰기), 학과장에게 제출 = 학과장에게 보내기, 취소 = 방금 쓴 것 되돌리기.
  • 제출한 내용은 학과장이 확정해야 홈페이지에 나옵니다.
  • 오른쪽 아래 창이 버튼을 가리면 창의 빈 곳을 끌어 옮기세요(제목을 두 번 누르면 원래 자리).
  • 화면이 예전 모양이면 Ctrl + Shift + R로 새로고침하세요.

커리큘럼

수업 커리큘럼을 처음 쓸 때
  1. 내 커리큘럼 위쪽에서 수업 구분 "일반 수업" → 학과 → 과목을 고릅니다.
  2. 왼쪽 1~4단계에 수업 내용을 씁니다(4단계를 모두 써야 제출됩니다).
  3. 단계마다 설명 이미지를 넣습니다(아래 "이미지를 넣을 때").
  4. 오른쪽 준비물을 적습니다.
  5. 오른쪽 아래 학과장에게 제출.
방학 특강 커리큘럼을 쓸 때

수업 구분을 "방학 특강"으로 → 방학 특강(예: 2026년 겨울방학특강) → 과목을 고른 뒤 똑같이 씁니다. 학과장이 특강에 넣은 과목만 나옵니다.

단계 이미지를 넣을 때
  • 단계 카드의 이미지 칸("설명 이미지 없음 · 눌러서 올리기")이나 이미지 수정을 누르고 파일을 고르거나 끌어다 놓습니다.
  • 컴퓨터의 이미지를 단계 카드 위에 바로 끌어다 놓아도 됩니다.
  • 홈페이지 카드에 보일 부분 고르기: 마우스 휠로 확대·축소, 끌어서 위치 → 이 부분으로 첨부.
  • 빼려면 이미지 빼기.
다 못 쓰고 나중에 이어서 쓸 때

오른쪽 아래 임시 저장. 다음에 같은 과목을 고르면 그대로 이어집니다. 다른 과목으로 넘어가면 쓰던 내용은 자동으로 임시 저장됩니다.

쓰던 내용을 버리고 싶을 때
  • 방금 쓴 것만: 취소.
  • 임시 저장한 것까지: 되돌리기(지금 제출·공개된 내용으로 돌아갑니다).
제출한 뒤 다시 고치고 싶을 때

같은 과목을 다시 고르고 고친 뒤 학과장에게 제출하면 됩니다. 학과장이 확정하기 전까지 홈페이지는 예전 내용 그대로입니다.

준비물

준비물을 여러 개 적을 때
  1. + 준비물을 누르면 한 줄이 생깁니다.
  2. 왼쪽에서 분류(교재·준비물·사용 프로그램·AI 도구)를 고르고 내용을 씁니다. AI 도구는 링크도 적을 수 있습니다.
  3. 더 있으면 다시 + 준비물. 필요 없는 줄은 빼기.
다른 과목에 적었던 준비물을 다시 쓸 때

+ 준비물 옆 내 준비물에서 불러오기를 열고 고릅니다. 임시 저장·제출할 때 적은 준비물이 여기에 모입니다.

프로필

경력·한마디·사진을 바꿀 때
  1. 내 프로필에서 이름·경력·수강생에게 한마디를 고칩니다.
  2. 사진은 사진 칸을 누르거나 끌어다 놓고, "본인 사진을 쓰는 것에 동의합니다"를 체크합니다.
  3. 학과장에게 제출. 홈페이지용 프로필 사진은 학과장이 검수할 때 AI로 만듭니다.

이럴 땐

"연결된 강사 정보가 없습니다" / "연결된 학과가 없습니다"가 뜰 때

계정이 강사 정보나 학과와 아직 연결되지 않았습니다. 학과장에게 연결을 요청하세요.

내 과목이 목록에 없을 때

일반 수업은 학과장이 학과에 넣은 과목, 방학 특강은 그 특강에 넣은 과목만 나옵니다. 학과장에게 과목 추가를 요청하세요.

제출이 안 될 때("내용을 채워주세요")

1~4단계 중 비어 있는 단계가 있습니다. 네 단계를 모두 쓰고 다시 제출하세요.
