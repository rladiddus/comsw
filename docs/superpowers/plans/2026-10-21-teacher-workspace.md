# 기존 구조를 유지하는 교사 작업 화면

사용자 승인: 기존 구조와 방향을 유지하여 진행(2026-10-21).

Firebase(ssamtalk-sbs) 로그인, 빌드 없는 ES 모듈, Supabase 콘텐츠 표와 승인/적용 스냅샷, GitHub Pages를 유지한다. 공개 사이트의 화면과 데이터 칸은 바꾸지 않는다.

- [x] 교사는 `mine`, `profile`만, 관리자·학과장은 기존 전체 메뉴와 두 메뉴 모두 사용한다.
- [x] 기존 강사는 이름 후보를 제시하고 관리자가 연결한다. 새 강사는 본인 계정으로 비공개 강사 정보를 만든다.
- [x] 학과·과목·학과 탭·주차를 선택하여 원문/이미지를 제출한다. 요약은 학과장·관리자가 처리한다. 승인된 줄의 수정은 새 pending 줄로 저장한다.
- [x] 경력·한마디·비공개 원본 사진과 생성 프로필을 임시 저장하고, 관리자가 확인 후 승인한다.
- [x] 공용 이미지 칸에 파일 선택/드롭 업로드를 붙인다. 관리자 Drive OAuth 갱신 토큰은 Edge Function 비밀값에만 둔다.
- [x] 기존 세 가지 요약 지시문과 프로필 지시문을 옮긴다. 변경 없는 요약은 재사용하고, DB에서 월 3,000원 예산을 잠금/예약하여 동시 호출도 제한한다.
- [x] 신청자 raw 데이터만 제거하는 SQL과 동기화 트리거만 제거하는 GAS 도구를 준비한다. keepSupabaseAlive 및 다른 raw 행은 유지한다.
- [x] 기존 주황색을 유지한 반응형 관리 화면으로 다듬는다. 의미 있는 권한·승인·제출·업로드·예산 테스트와 전체 기존 테스트를 실행한다.

추가 요청: 교사 예산 안내 삭제, 커리큘럼 이미지 선택 후 최소 1000px 정사각형 크롭, AI 요약·프로필 생성의 학과장·관리자 전용 처리. 화면·서버 권한·사진 동의·이미지 해상도 검증에 반영했다.

결과: 로컬 테스트 185개, 문법 125건, Deno 검사 및 이미지 처리 3개 통과. 운영에는 신청자 raw 공개 읽기 차단만 먼저 반영·확인했다. 새 기능의 운영 SQL/서버 배포/Secrets/실제 업로드·AI 검증/main 반영은 별도 후속 작업으로 남는다.

운영 DB 도구는 현재 permission denied. 운영 SQL 실행, OAuth/OpenAI 비밀값 설정, GAS 실제 트리거 정리와 main 공개는 로컬 구현과 구분하여 기록한다. 비밀값·신청자 데이터는 저장소에 쓰지 않는다.
